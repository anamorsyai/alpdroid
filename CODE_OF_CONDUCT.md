# Code of Conduct

AlpDroid is a small open-source project. We want it to be a friendly, useful place for everyone who uses or
contributes to it.

## Our standard

- Be respectful and patient, especially with people who are new to Linux or Android.
- Give and accept constructive feedback; critique code and ideas, not people.
- Assume good intent, and ask before assuming.
- No harassment, discrimination, personal attacks, or unwelcome sexual attention.
- Don't publish other people's private information.

## Scope

This applies to issues, pull requests, discussions and any other project space.

## Enforcement

Maintainers may edit or remove comments, close threads, or block people who break these rules. To report a
problem, use GitHub's *Report content* feature or the private vulnerability reporting described in
[SECURITY.md](SECURITY.md) if it is sensitive.

This policy is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.

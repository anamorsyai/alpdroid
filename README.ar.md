**AlpDroid** يشغّل نظام [Alpine Linux](https://alpinelinux.org) حقيقيًا على هاتف أندرويد — بدون root وبدون
جهاز افتراضي وبدون سحابة. ثبّت الحزم بـ `apk`، شغّل Node.js وPython وgit، افتح سيرفر SSH أو واجهة ويب،
واستخدم أدوات البرمجة بالذكاء الاصطناعي من سطر الأوامر (opencode وClaude Code وغيرها) من طرفية مصمَّمة
للمس من الصفر.

## أهم المميزات

- **لينكس حقيقي بدون root** — Alpine يعمل بدون صلاحيات عبر `proot`، ولا يمس باقي النظام. حجم التطبيق حوالي 2.4 ميجا فقط.
- **طرفية مصمَّمة للهاتف** — تبويبات متعددة، محاكي طرفية خاص، ألوان كاملة، رموز تعبيرية وحروف عريضة، دعم الماوس للتطبيقات النصية،
  تكبير بالقرص، بحث، وصف مفاتيح إضافية (ESC وTAB وCTRL وALT والأسهم) مع أزرار اختصار خاصة بك.
- **سيرفرات بضغطة واحدة** — سيرفر **SSH** للدخول من اللابتوب (`ssh -p 8022 root@<عنوان الهاتف>` بكلمة مرور يولّدها التطبيق أو بمفتاح عام)،
  وواجهة **opencode على الويب** تعمل في الخلفية: تفتح على الهاتف نفسه بدون تسجيل دخول، ولباقي الأجهزة على الشبكة برابط جاهز. لكل سيرفر أزرار Stop وLog وOpen.
- **جاهز للـ agents** — تثبيت opencode وClaude Code وalphacode بضغطة، وأزرار لتشغيلها، وتسجيل دخول GitHub ليعمل `git` مباشرة،
  وواجهة `alpctl` المحمية بمفتاح ليتحكم الـ agent في التطبيق (معطّلة افتراضيًا).
- **AlpBrowser — متصفح الـ agent** — تطبيق مرافق منفصل لاختبار الثغرات (bug bounty) وتطوير الويب. تصفّح مباشر وسريع بتبويبات وحاجب إعلانات،
  ومع تشغيل Capture تحصل على Proxy بأسلوب Burp (إيقاف الطلبات والردود وتعديلها وتمريرها أو إسقاطها، سجل بحث، قواعد بحث-واستبدال)
  وRepeater وإضافات (userscripts) تبقى مثبّتة. يقدر الـ agent أن يضغط ويملأ النماذج وينتظر العناصر وينفّذ JavaScript ويلتقط لقطات شاشة
  ويحفظ الأدلة ويصدّر HAR ويدير الـ cookies ويسلّم الصفحة لـ Playwright أو Puppeteer — بدون أي توكنات تنسخها على هاتفك.
  التفاصيل في [دليل AlpBrowser](docs/ALPBROWSER.md) (بالإنجليزية).
- **إضافات وأتمتة** — أنشئ شاشات وأزرارًا خاصة بك في الإعدادات عبر `plugin.json` أو ملف `.ad` واحد قابل للمشاركة، مع مهام مجدولة. كل إضافة تحتاج موافقتك قبل التشغيل.
- **بارد وخفيف** — مدير موارد ذكي يخفّض معدل إعادة الرسم عند السخونة أو توفير البطارية، ويقلّص الذاكرة عند الضغط، ويغلق الجلسات المجمّدة،
  ويوزّع الحمل على الأنوية، ويمنع امتلاء `/tmp`.
- **يعمل في الخلفية** — خدمة تعمل في المقدمة مع wake lock وWi-Fi lock لتبقى السيرفرات والعمليات الطويلة شغالة والشاشة مقفولة،
  ويخبرك AlpDroid بوضوح إذا أوقفه أندرويد.
- **ملفاتك من الجهتين** — مدير ملفات لأندرويد وAlpine، و`/sdcard` وفلاشات USB/SD ظاهرة داخل لينكس، ونسخ احتياطي للنظام كله في ملف واحد مع نسخ أسبوعي تلقائي اختياري.
- **تحديث ذاتي** — يفحص AlpDroid الإصدارات الجديدة ويحمّلها ويتحقق منها ثم يثبّتها فوق القديمة، ويحدّث AlpBrowser بنفس الطريقة.
- **آمن وخصوصي** — بدون تتبع أو إعلانات، والمفاتيح مخزّنة مشفّرة في Android Keystore، وأي إضافة أو صلاحية للـ agent تحتاج موافقتك.

## التثبيت

1. حمّل أحدث ملف **`AlpDroid-vX.Y.Z.apk`** (حوالي 2.4 ميجا) من صفحة [Releases](https://github.com/anamorsyai/alpdroid/releases/latest)
2. افتح الملف واسمح بالتثبيت من المتصفح أو مدير الملفات.
3. شغّل التطبيق؛ أول مرة يحمّل نظام Alpine الأساسي الصغير (حوالي 3-4 ميجا، يلزم إنترنت).
4. اسمح بـ **All files access** إن أردت `/sdcard` داخل لينكس.

التحديثات تُثبَّت فوق النسخة القديمة لأن كل الإصدارات موقّعة بنفس المفتاح، والتطبيق يفحص التحديثات بنفسه.

**المتطلبات:** أندرويد 7.0 أو أحدث · معالج arm64 أو armv7 أو x86_64 أو x86.

**الحجم:** ملف APK حوالي 2.4 ميجا، وتحميل نظام Alpine الأساسي أول مرة حوالي 3-4 ميجا، والمساحة بعد الإعداد (التطبيق + النظام الأساسي) أقل من 15 ميجا — لأن AlpDroid يستخدم Alpine minirootfs وهو أصغر نسخة رسمية. أي أدوات تثبّتها بعد كده (Node.js وPython وgit...) تزيد حجمها فوق ده.

## أسئلة شائعة

**هل هو root أو جهاز افتراضي؟** لا. Alpine يعمل كعمليات عادية تحت `proot` الذي يحاكي root داخل النظام الضيف فقط.

**هل أقدر أشغّل برامج رسومية؟** لا، هو بيئة طرفية (أدوات سطر الأوامر والسيرفرات).

**ليش العمليات تتوقف في الخلفية؟** أندرويد قد يقتل التطبيقات في الخلفية. أبقِ إشعار الخدمة شغالًا، واسمح
باستخدام البطارية *Unrestricted*، وأبقِ الـ wake lock مفعّلًا للمهام الطويلة. الجلسات المفتوحة لا تنجو من
قتل النظام، أما الملفات فتبقى. في أندرويد 12+ بعض الأجهزة تحدّ من العمليات الفرعية أيضًا — راجع قسم
Troubleshooting في الدليل.

**ما هو AlpBrowser وهل أحتاجه؟** اختياري. هو متصفح منفصل يتحكم فيه الـ agent لاختبار الثغرات وتطوير الويب. ثبّته من الإعدادات ← About ← AlpBrowser،
والتفاصيل في [دليل AlpBrowser](docs/ALPBROWSER.md).

**هل أحتاج توكن أو كلمة مرور بين AlpDroid وAlpBrowser؟** لا، على هاتفك يتعرّف كل منهما على الآخر تلقائيًا. إعداد *Open local access* في AlpBrowser
(مفعّل افتراضيًا) يسمح للبرامج على الهاتف بالتحكم فيه بدون توكن مع رفض صفحات الويب دائمًا، ويمكنك إيقافه. باقي صلاحيات الـ agent
(`alpctl` والإضافات ومشاركة توكن GitHub) اختيارية أو تطلب موافقتك.

**هل هو آمن؟** الضيف (guest) موثوق مثل Termux: أي برنامج تشغّله له نفس صلاحيات التطبيق. المفاتيح مخزّنة مشفّرة في Keystore، وصلاحيات الـ agent
والإضافات تحتاج موافقتك. التفاصيل في [SECURITY.md](SECURITY.md).

**هل يجمع بيانات؟** لا. راجع [PRIVACY.md](PRIVACY.md).

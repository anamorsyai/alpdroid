**AlpDroid** يشغّل نظام [Alpine Linux](https://alpinelinux.org) حقيقيًا على هاتف أندرويد — بدون root وبدون
جهاز افتراضي وبدون سحابة. ثبّت الحزم بـ `apk`، شغّل Node.js وPython وgit، افتح سيرفر SSH أو واجهة ويب،
واستخدم أدوات البرمجة بالذكاء الاصطناعي من سطر الأوامر (opencode وClaude Code وغيرها) من طرفية مصمَّمة
للمس من الصفر.

## أهم المميزات

- **لينكس حقيقي بدون root** — Alpine يعمل بدون صلاحيات عبر `proot`، ولا يمس باقي النظام.
- **طرفية مصمَّمة للهاتف** — تبويبات متعددة، محاكي طرفية خاص، ألوان كاملة، دعم الماوس للتطبيقات النصية،
  تكبير بالقرص، وصف مفاتيح إضافية (ESC وTAB وCTRL وALT والأسهم) مع أزرار اختصار خاصة بك.
- **سيرفر SSH بضغطة واحدة** — من الإعدادات ← Network & SSH ← *Start SSH server*، فتدخل من اللابتوب
  بالأمر `ssh -p 8022 root@<عنوان الهاتف>` وبكلمة مرور يولّدها التطبيق، أو بمفتاح عام عبر *Add SSH public key*.
- **واجهة opencode على الويب بضغطة** — تفتحها من أي جهاز على نفس شبكة الواي فاي.
- **جاهز للـ agents** — تثبيت opencode وClaude Code وalphacode بضغطة، وأزرار لتشغيلها، وواجهة `alpctl`
  المحمية بمفتاح ليتحكم الـ agent في التطبيق.
- **يعمل في الخلفية** — خدمة تعمل في المقدمة مع wake lock وWi-Fi lock لتبقى السيرفرات والعمليات الطويلة
  شغالة والشاشة مقفولة.
- **ملفاتك من الجهتين** — مدير ملفات لأندرويد وAlpine، و`/sdcard` وفلاشات USB/SD ظاهرة داخل لينكس.
- **آمن وخصوصي** — بدون تتبع أو إعلانات، والمفاتيح مخزّنة مشفّرة في Android Keystore، وأي إضافة أو صلاحية
  للـ agent تحتاج موافقتك.

## التثبيت

1. حمّل أحدث ملف **`AlpineTerm-vX.Y.Z.apk`** من صفحة [Releases](https://github.com/anamorsyai/alpdroid/releases/latest)
   (اسم الملف يحتفظ بالبادئة القديمة ليعمل التحديث).
2. افتح الملف واسمح بالتثبيت من المتصفح أو مدير الملفات.
3. شغّل التطبيق؛ أول مرة يحمّل Alpine (يلزم إنترنت، ويُفضَّل مساحة ~500 ميجا).
4. اسمح بـ **All files access** إن أردت `/sdcard` داخل لينكس.

التحديثات تُثبَّت فوق النسخة القديمة لأن كل الإصدارات موقّعة بنفس المفتاح، والتطبيق يفحص التحديثات بنفسه.

**المتطلبات:** أندرويد 7.0 أو أحدث · معالج arm64 أو armv7 أو x86_64 أو x86.

## أسئلة شائعة

**هل هو root أو جهاز افتراضي؟** لا. Alpine يعمل كعمليات عادية تحت `proot` الذي يحاكي root داخل النظام الضيف فقط.

**هل أقدر أشغّل برامج رسومية؟** لا، هو بيئة طرفية (أدوات سطر الأوامر والسيرفرات).

**ليش العمليات تتوقف في الخلفية؟** أندرويد قد يقتل التطبيقات في الخلفية. أبقِ إشعار الخدمة شغالًا، واسمح
باستخدام البطارية *Unrestricted*، وأبقِ الـ wake lock مفعّلًا للمهام الطويلة. الجلسات المفتوحة لا تنجو من
قتل النظام، أما الملفات فتبقى. في أندرويد 12+ بعض الأجهزة تحدّ من العمليات الفرعية أيضًا — راجع قسم
Troubleshooting في الدليل.

**هل يجمع بيانات؟** لا. راجع [PRIVACY.md](PRIVACY.md).
